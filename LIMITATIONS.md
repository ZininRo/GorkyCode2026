## 2. Сознательные отклонения от ТЗ (согласовать в команде)

1. **Гостевой вход без пароля (`POST /guests`) не реализован.** По вашему указанию сохранена готовая регистрация (email, пароль, город). Язык выбирается переключателем RU/EN (хранится в браузере), страна берётся из выбранного города. Поле «страна» отдельно не вводится, а другие страны недоступны, пока справочник городов содержит только RU.
2. **После входа и регистрации** открывается `/profile`, а не `/home`: это поведение существующих LoginPage/RegisterPage, их я не менял. С профиля одно нажатие до главной и квеста.
3. **Токен** хранится в памяти + HttpOnly refresh-cookie (существующая, более безопасная схема) вместо `localStorage` из ТЗ. Прогресс после перезагрузки восстанавливается.
4. **Названия маршрутов и точек** в API возвращаются как `{ru, en}`. Также добавлены поля сверх примеров ТЗ (см. `docs/API_CONTRACT_MVP.md`).
5. **Уровень «Знаток города» (130+)** не включён: по ТЗ это расширение после MVP. Добавляется одной строкой в `TouristLevel` и новой миграцией с маршрутом `requiredScore=130`.

## 4. Технические ограничения и риски

- **Карта** (Leaflet 1.9.4) подгружается с `unpkg.com`, тайлы берутся с `tile.openstreetmap.org`, без SRI-хэша. Без интернета вместо карты показывается список точек, сбор работает. Для продакшена: добавить `leaflet` в `package.json` (решение Егора) и использовать свой tile-провайдер (у OSM есть политика использования).
- **Геолокация** работает только по HTTPS или на `localhost`. Для телефона нужен HTTPS-туннель (SETUP_GUIDE, раздел 4). `compose.yaml` публикует порты только на `127.0.0.1`.
- **Демо-режим** (`GAME_DEMO_MODE=true`) позволяет собрать любую открытую точку без поездки. Сервер всё равно проверяет дистанцию, но координаты присылает клиент. Это верно и для обычного режима: GPS клиента можно подделать (DevTools). Полная защита от подмены GPS в рамках веб-MVP невозможна. Не включайте демо на публичном сервере.
- **ИИ:** поддерживается любой OpenAI-совместимый API (OpenAI, OpenRouter, Ollama и т.п.). YandexGPT подключается через OpenAI-совместимый API Yandex Cloud (`YANDEX_SETUP_GUIDE.md`); реальный вызов YandexGPT при подготовке не проверялся (нет ключа и сети). GigaChat без совместимого шлюза не подключится: нужна отдельная реализация `LlmClient`. Вызов синхронный (таймаут по умолчанию 8 с, для YandexGPT рекомендовано 15 с), кэш подсказок в памяти процесса. Фильтр `AiTextGuard` отклоняет ответы с числами, которых нет в фактах. Это снижает, но не исключает риск выдумок: текст ИИ помечается в UI.
- **AuthContext:** добавлен метод `authRequest`. Пока Егор его не подтвердит, эта правка остаётся в статусе запроса (см. SHARED_CHANGE_REQUESTS).
- **SecurityConfig и compose.yaml:** правки в общих файлах выполнены, чтобы проект запускался. Формально они требуют подтверждения Ромы (запросы в `docs/integration/SHARED_CHANGE_REQUESTS.md`).
- Подключение `styles/index.css` в `main.tsx` применяет `reset.css` ко всем страницам, включая Login/Register. Вид этих форм может немного измениться.
- Офлайн-режима и Service Worker нет.
- `GET /checkpoints` и `GET /game` используют один и тот же запрос; при больших объёмах контента нужна пагинация (для 6 точек не требуется).
- Отдельного integration-теста с Testcontainers для game/ai нет: сценарий раздела 11 покрыт unit-тестом `GameServiceTest` и `scripts/smoke-test.sh`.
